# Hospital Data Analysis Dashboard (Excel)

## Dashboard Preview

![Hospital Excel Dashboard](hospital_dashboard_preview.png)

## Project Overview

This project analyzes hospital patient data using Microsoft Excel. The dashboard provides insights into patient admissions, departmental performance, revenue generation, and payment status.

## Tools Used

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Slicers
* KPI Cards

## Key Metrics

* Total Patients
* Total Revenue
* Pending Payment Amount
* Average Treatment Cost
* Average Stay Duration

## Dashboard Preview

![Hospital Dashboard](excel_hospital_dashboard_preview.png)

## Insights

* Cardiology generated the highest revenue among departments.
* A significant portion of payments remain pending.
* Admission trends remain relatively stable over the analyzed period.
